# testapp

Scaffolded with [`strand`](https://github.com/strand/strand).

## Run

```bash
yarn install
strand dev
```

Active strands: see `strand.json`.

## Layout

- `shared/` — Zod-typed API contract (single source of truth for backend + frontend)
- `backend/` — Express API server
- `web-app/` — Vite + React SPA
- `docker-compose.yml` — Postgres + other services (regenerated by `strand`)
- `.claude/skills/` — agent-facing workflows

## Adding an endpoint

1. Add a schema to `shared/src/api/routes.ts`.
2. Register a handler in `backend/src/api.ts` via `serveEndpoint(app, ApiSchema.x, handler)`.
3. Call it from the frontend via `callEndpoint(ApiSchema.x, input)`.

Types flow automatically across all three.
